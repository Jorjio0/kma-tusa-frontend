# KMA Tusa — фронтенд

React-фронтенд для афіші студентських тусовок Могилянки: вечірок, квартирників, ночей настолок, караоке тощо. Працює з бекендом [kma-tusa](https://github.com/Jorjio0/kma-tusa) (Django REST).

Зроблено на основі навчального шаблону [fprn_FE_educational_project](https://github.com/SandraRadz/fprn_FE_educational_project): сторінки ресурсів переписані під KMA Tusa, оформлення змінене.

## Як запустити проєкт

Потрібен Node.js 18 або новіший (`node --version`).

1. Запустіть бекенд за інструкцією з [README бекенду](https://github.com/Jorjio0/kma-tusa#як-запустити-проєкт). Він має працювати на http://localhost:8000.
2. У папці фронтенду встановіть залежності й запустіть сервер розробки:

```bash
npm install
npm run dev
```

3. Відкрийте http://localhost:5173.

## Порти

| Що | Адреса |
| --- | --- |
| Фронтенд (Vite) | http://localhost:5173 |
| Бекенд (Django) | http://localhost:8000, API: http://localhost:8000/api/ |

Фронтенд звертається до бекенду на `http://localhost:8000`. Якщо бекенд працює на іншій адресі, скопіюйте `.env.example` у `.env`, змініть `VITE_API_URL` і перезапустіть `npm run dev`.

Бекенд дозволяє запити з `http://localhost:5173` і `http://127.0.0.1:5173` через CORS (`CORS_ALLOWED_ORIGINS` у `config/settings.py`). Якщо змінити порт фронтенду, його треба додати й туди.

## Сторінки

| Сторінка | Адреса | Ресурс API |
| --- | --- | --- |
| Головна | `/` | — |
| Тусовки | `/events` | `/api/events/` |
| Організатори | `/organizers` | `/api/organizers/` |
| Локації | `/venues` | `/api/venues/` |
| Категорії | `/categories` | `/api/categories/` |

- На кожній сторінці ресурсу є форма (**Створити** / **Зберегти зміни**), кнопка **Отримати список** і кнопки **Редагувати** та **Видалити** в рядках таблиці.
- На сторінці тусовок категорія, організатор і локація обираються зі списків, які підтягуються з API.
- Помилки валідації від сервера (`400`) показуються під відповідними полями форми, наприклад «Час завершення має бути пізніше за час початку.».
- Помилки `404` і `409` показуються над таблицею, наприклад «Неможливо видалити категорію Вечірка: у ній є тусовки (3).».
- Панель **«Відповідь сервера»** у правому нижньому куті показує метод, адресу, статус, тіло й хедери останньої відповіді.

## Структура

```
src/
  api.js              запити до бекенду (list, create, update, remove)
  hooks.js            завантаження довідників для випадних списків
  App.jsx             шапка, навігація й маршрути
  components/
    CrudPage.jsx      спільна сторінка: форма + таблиця
    ResponsePanel.jsx панель «Відповідь сервера»
  pages/
    Home.jsx
    Events.jsx
    Organizers.jsx
    Venues.jsx
    Categories.jsx
  styles.css
```
